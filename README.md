# 望道 SNN 项目

本项目围绕事件相机目标检测模型的 ANN 改进、SNN 转换、近似计算和 FPGA 部署展开。当前主线以原始两级 MLP/H2 模型为基线，先完成传统 ANN 范围内的模型改进与统一评测，再逐步转换为 SNN，并面向 KV260 开发板开展硬件实现。

## 当前模型结论

- 原始 H2 是 ANN 基线，也是后续 SNN 研究的教师模型。
- H2-plus 是 H2 改进计划最终入选模型，历史实验 ID 为 `A4-2`。
- 正式软件评测采用 `exact_int8_replay`：uint8 激活、int8 权重、int32 乘加。
- 当前结果属于软件精确整数回放，不等同于 KV260 板级实测；硬件结果将在目录 2 和 4 完成后单独报告。

正式模型对比、Validation/Test PR 曲线和指标表见 [`5、模型评测指标/`](5、模型评测指标/README.md)。

## GitHub 发布范围

本仓库当前只发布编号 0—5 的六个目录：

- `0、1、5`：上传当前项目内容。
- `2、3、4`：只保留目录占位，待相关工作完成后再上传具体内容。

本地的 `立项汇报/`、`archive/`、`tmp/` 不在本次发布范围内。外部数据集链接、缓存、训练 checkpoint、日志及工具生成目录继续按各子工程的 `.gitignore` 规则排除，不作为 GitHub 仓库内容。

## 大文件说明

仓库中的大型 ZIP/NPZ 研究结果使用 Git LFS 管理。首次克隆前请安装 Git LFS，并执行 `git lfs install`；正常执行 `git clone` 时会自动下载这些文件，如未自动下载可在仓库目录执行 `git lfs pull`。

## 使用说明

各子工程的运行入口、数据边界和验证方法以对应目录内的 `README.md` 与 `AGENTS.md` 为准。数据划分严格区分 Train-main、Train-dev、HW-calibration、Validation 和 Test；不得使用 Test 重新选择模型、阈值或量化参数。
