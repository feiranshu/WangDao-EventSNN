# 望道 SNN 项目

本项目围绕事件相机目标检测模型的 ANN 改进、SNN 转换、近似计算和 FPGA 部署展开。当前主线以原始两级 MLP/H2 模型为基线，先完成传统 ANN 范围内的模型改进与统一评测，再逐步转换为 SNN，并面向 KV260 开发板开展硬件实现。

## 当前模型结论

- 原始 H2 是冻结的 ANN 基线，也是后续 SNN 研究的教师模型。
- H2-plus 是 H2 改进计划最终入选模型，历史实验 ID 为 `A4-2`；正式版本采用 seed 42、epoch 8。
- 当前正式比较采用 `exact_int8_replay`：uint8 激活、int8 权重、int32 乘加。准确度协议为 `evuav-33e2aff-official-compatible-v1+step3-density-20000`。
- H2 的冻结工作点阈值为 0.30，H2-plus 为 0.40；Validation 和 Test 只作冻结后的独立报告，不用于重新选择模型、阈值或量化参数。
- 当前已完成的准确度与复杂度结果属于软件评测，不等同于 KV260 板级实测。目录 3 已保存第一代 SNN 软件研究，但 H2/H2-plus 尚无纳入统一正式评测的可比 SNN 结果；部署效率、硬件成本和正式 ANN/SNN 差异将在目录 2—4 形成冻结结果后补充。

目录 5 只让正式入选模型进入 A—D 四类评测。目前正式模型为 H2 与 H2-plus；未入选模型、消融实验和历史诊断证据统一放入 `附：中间产物模型/`，默认不混入正式结果与对比图。

| 类别 | 评测内容 | 当前状态 |
| --- | --- | --- |

## GitHub 发布范围

本仓库当前只发布编号 0—5 的六个目录：

- `0、1、3、5`：上传当前项目内容。
- `2、4`：只保留目录占位，待相关工作完成后再上传具体内容。

本地的 `立项汇报/`、`archive/`、`tmp/` 不在本次发布范围内。外部数据集链接、缓存、训练 checkpoint、日志及工具生成目录继续按各子工程的 `.gitignore` 规则排除，不作为 GitHub 仓库内容。

## 大文件说明

仓库中的部分大型 ZIP/NPZ 研究结果使用 Git LFS 管理。首次克隆前请安装 Git LFS，并执行 `git lfs install`；正常执行 `git clone` 时会自动下载这些文件，如未自动下载可在仓库目录执行 `git lfs pull`。

## 使用说明

各子工程的运行入口、数据边界和验证方法以对应目录内的 `README.md` 与 `AGENTS.md` 为准。数据划分严格区分 Train-main、Train-dev、HW-calibration、Validation 和 Test；不得使用 Test 重新选择模型、阈值或量化参数。
