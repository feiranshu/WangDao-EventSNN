# KV260 官方硬件手册入口

AMD 已将 KV260/K26 的固定 PDF 下载页迁移至 AMD Technical Information Portal。本目录不保存跳转网页伪装成的 `.pdf`；请通过下列官方原文查阅并使用页面的下载/打印功能。

- [UG1089：KV260 Starter Kit User Guide](https://docs.amd.com/r/en-US/ug1089-kv260-starter-kit/Software-Getting-Started)
- [DS986：KV260 Starter Kit Data Sheet](https://docs.amd.com/r/en-US/ds986-kv260-starter-kit/Product-Details)
- [DS987：K26 SOM Data Sheet](https://docs.amd.com/v/u/en-US/ds987-k26-som)
- [UG1085：Zynq UltraScale+ MPSoC Technical Reference Manual](https://docs.amd.com/v/u/en-US/ug1085-zynq-ultrascale-trm)

优先级：先读 UG1089；开始写 PL/AXI/DMA 时再查 UG1085；核对资源、管脚和电气条件时查 DS986/DS987。
