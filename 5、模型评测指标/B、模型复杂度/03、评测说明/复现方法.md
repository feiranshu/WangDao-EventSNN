# B 类复现方法

在 `1、H2模型改进/implementation/` 下运行：

```powershell
python software/scripts/generate_model_complexity_report.py
python software/scripts/generate_model_complexity_report.py --memory-only
python software/scripts/generate_model_complexity_report.py --plot-only
```

第一条从冻结索引和权重重算 H2/H2-plus；第二条补充软件追踪堆峰值；第三条从已保存结果重建 `指标汇总.csv` 和 Validation/Test 柱状图。程序逐序列核对 A 类事件数与候选数。

复杂度工作簿由 `software/scripts/generate_model_complexity_workbook.mjs` 生成；EV-SpSegNet 官方仓库参数核对由 `software/scripts/verify_evuav_complexity.py` 复算。所有生成代码位于实现工程，B 只保存结果、图表和说明。
