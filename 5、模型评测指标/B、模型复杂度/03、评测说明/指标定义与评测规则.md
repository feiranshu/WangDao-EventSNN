# B 类指标定义与评测规则

本目录评估算法本身的资源需求，不等同于板级速度、功耗或 FPGA 资源。H2/H2-plus 使用与 A 一致的冻结 exact-INT8 Proposal+Refiner；共享 Proposal 只计一次。

| 编号 | 指标 | 统一口径 |
| --- | --- | --- |
| A01 | 参数量 | int8 权重矩阵元素数，包含零权重。 |
| A02 | 静态存储 | 权重 int8 字节与每输出通道 float32 量化尺度；不使用 NPZ/ZIP 文件大小。 |
| A03 | 工作/状态内存 | 核心张量体积预算与 Python/NumPy 追踪堆峰值分开报告；均不等同于板级 SRAM/RSS。当前 ANN 持久神经元状态为 0。 |
| A04 | 稠密 MAC | 全部 Proposal 调用和实际 Refiner 候选调用的结构运算量。 |
| A05 | 有效 MAC/AC | 非零输入连接到非零权重的潜在 MAC；当前回放仍执行稠密矩阵乘。ANN 的 SNN AC 不适用，记 0。 |
| A06 | 其他运算 | 激活量化变换、sigmoid、softmax、历史特征和 SNN 神经元更新分项报告，不强行相加。 |

参数量与静态存储是模型通用属性，只在汇总表出现一次；输入相关指标按 Validation、Test 分开报告。两套数据各包含 24 条完整 8 s 序列，每条执行 80 个 100 ms Proposal 窗口。

EV-SpSegNet 只作为外部参照。原论文仅报告约 4.0M 参数，因此 A01 使用论文值；A02—A06 保持未报告。官方仓库提交 `33e2affb51a204676536e119803ab8494e2eb0a9` 的代码核对值不替代论文基线。
