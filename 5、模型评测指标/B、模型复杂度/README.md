# B、模型复杂度

本目录保存正式模型的算法层复杂度结果，以及 EV-SpSegNet 的论文外部参照。目录格式与 A 完全一致：**看结论去 01，查原数去 02，查口径去 03**。

```text
B、模型复杂度/
├─ README.md
├─ 01、对比图表/
│  ├─ 指标汇总.csv
│  ├─ 模型复杂度逐序列明细.xlsx
│  ├─ Validation/01_模型复杂度.png
│  └─ Test/01_模型复杂度.png
├─ 02、评测数据/
│  ├─ H2/summary.json
│  ├─ H2-plus/summary.json
│  └─ EV-SpSegNet/论文参考.json
└─ 03、评测说明/
   ├─ 指标定义与评测规则.md
   └─ 复现方法.md
```

## 快速入口

| 想查什么 | 去哪里 |
| --- | --- |
| A01—A06 对比 | `01、对比图表/指标汇总.csv` |
| 主要柱状图 | `01、对比图表/Validation/` 或 `Test/` |
| 96 行逐序列核对 | `01、对比图表/模型复杂度逐序列明细.xlsx` |
| 某个模型的汇总和逐序列源数据 | `02、评测数据/<模型>/` |
| 指标口径与复现命令 | `03、评测说明/` |

H2/H2-plus 已完成 A01 参数量、A02 静态存储、A03 工作/状态内存、A04 稠密 MAC、A05 有效 MAC/AC 和 A06 其他关键运算。EV-SpSegNet 仅有原论文 A01 约 4.0M 参数可进入对比，其余保持 N/A。B 的结果是软件算法评测，不是 KV260 延迟、功耗或资源实测；那些结果归 C。

本目录不保存生成脚本、权重或缓存。正式生成代码统一位于 `1、H2模型改进/implementation/software/scripts/`。
