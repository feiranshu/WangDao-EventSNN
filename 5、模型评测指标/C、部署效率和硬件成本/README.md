# C、部署效率和硬件成本

此目录只接纳**正式模型**的同条件实际部署结果。目前 H2 和 H2-plus 尚未完成所需的同平台上板测试，因此不生成正式数值或比较图；留空不代表 0。

| 主表编号 | 待测指标 | 必须注明的边界 |
| --- | --- | --- |
| B01 | 模型内核延迟 | 同一硬件、相同输入规模；与端到端延迟分开。 |
| B02 | 端到端延迟 | 包含输入、预处理、传输与后处理的明确起止点。 |
| B03 | 吞吐与实时性 | 输入序列/事件规模、持续运行条件和超时/积压。 |
| B04 | 运行功耗 | 明确整板、分轨或器件估算，不混用。 |
| B05 | 单位任务能耗 | 与测得的功耗及吞吐/延迟对应。 |
| B07 | 硬件资源/面积 | LUT、FF、BRAM、DSP 等报告所用器件与工具版本。 |

正式结果必须与 A/B 一样给出模型、数据划分、数值路径、平台、测量口径、原始记录及可追溯脚本。中间产物模型仅在用户明确要求时单独处理，不混入正式比较。
