# H2 改进计划中间产物模型

本目录保存 H2 七步改进研究中未入选的候选模型、匹配对照及旧的全模型横向比较结果。它们用于复盘与追溯，不作为当前正式模型目录。

包含：

- A2-1、A2-2：Step 2 密度采样与损失加权候选。
- A3-1、A3-2：Step 3 BCE 训练候选。
- A4-1、A4-1-null：密度特征及匹配零输入对照。
- A4-2-null：H2-plus 的历史零输入对照。
- A4-3、A4-3-control：删除 `sequence_time` 的诊断模型及匹配对照。
- `统一评测摘要.csv`：旧 11 模型 Train-dev int8 统一评测表。
- `全模型PR曲线对比_Train-dev.*`：旧全模型完整 PR 曲线对比图。

当前正式 H2 与 H2-plus 的 Validation/Test 图表位于 `A、模型准确度/01、对比图表/`；正式源数据位于其 `02、评测数据/`。
