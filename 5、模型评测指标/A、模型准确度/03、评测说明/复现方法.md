# A 类复现方法

正式结果生成代码不放在评测结果目录，统一位于 `1、H2模型改进/implementation/software/scripts/`。

## 重建汇总和图表

在 `1、H2模型改进/implementation/` 下运行：

```powershell
python software/scripts/generate_accuracy_reports.py
```

程序只读取 `02、评测数据/` 中冻结的 JSON/CSV，生成 `01、对比图表/指标汇总.csv` 及 Validation/Test 六类 PNG，不重新推理或调参。

## 重算目标轨迹

```powershell
python software/scripts/evaluate_target_tracks.py
```

该入口校验冻结权重哈希，在 Train-dev 复现后处理选择，再写入 H2/H2-plus 的 `目标轨迹级/` 目录和冻结协议文件。Validation/Test 不参与选择。

EV-SpSegNet 补测时提供 `<prediction_root>/<validation|test>/<sequence>.npz`；每个文件包含与原始事件严格同序的一维 `probabilities`：

```powershell
python software/scripts/evaluate_target_tracks.py --evuav-prediction-root <目录> --evuav-repo-commit <提交> --evuav-weight-sha256 <哈希>
```

导入后再运行图表生成器；不重新选择轨迹协议。
