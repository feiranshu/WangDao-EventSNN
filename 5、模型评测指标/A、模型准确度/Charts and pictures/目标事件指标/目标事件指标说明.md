# 目标事件指标说明

## 结论

背景事件确实会把常规总体准确率 `overall_accuracy=(TP+TN)/(TP+FP+FN+TN)` 抬高。当前正式结果中，Test 的总体准确率约为 99.5%，不适合判断目标检测能力。

现有 `Recall`（同时也是 EV-UAV 官方命名中的 `ACC`）已经是只统计目标事件的指标：

`Target-event Recall = TP / (TP + FN)`

其分母只包含真实目标事件，不包含背景事件或背景真负例。新图以该指标及 `Miss Rate = FN / (TP + FN)` 为核心，并同时给出总体、高密度、普通密度和序列宏平均结果。

## Pd 为什么仍然偏高

本项目的 EV-UAV 官方兼容规则按 50 ms 窗口和目标 ID 统计 `Pd=correct_targets/targets`。一个目标窗内的预测命中比例只要达到 `0.0001`（0.01%）就算正确检出，因此 `Pd` 很容易接近 1。它没有被背景真负例直接抬高，但判定门槛非常宽松，区分模型的能力弱于目标事件召回率和高密度目标事件召回率。

## 正式比较结果

- Validation：H2-plus 的总体目标事件召回率比 H2 高 0.3481 个百分点，高密度目标事件召回率高 1.9314 个百分点。
- Test：H2-plus 的总体目标事件召回率比 H2 低 0.2591 个百分点，高密度目标事件召回率低 1.2138 个百分点。
- 这说明 H2-plus 的正式优势主要来自更少的背景误报、更高的 Precision/IoU/F1；在独立 Test 上，它以很小的目标召回损失换取了更低的 Fa。不能用 99% 以上的总体准确率来概括这一权衡。

## EV-UAV 原论文基线与 AP

EV-UAV 原论文 Table 2 报告 EV-SpSegNet 的 `ACC=65.02%`、`Pd=77.53%`。同一张 Test 基准图中加入了 H2 与 H2-plus 的官方兼容 ACC/Pd，便于定位三者差异。

事件目标检测顶级论文通常使用 AP/mAP，例如 RVT（CVPR 2023）在 Gen1 上报告 mAP，EvDET200K（CVPR 2025）也采用 mAP。H2 与 H2-plus 没有边界框预测输出，因此不能严谨计算 COCO 式 bbox mAP；本项目改用完整事件级 Precision-Recall 曲线的面积 `Event AP`，它同样不依赖背景 TN：

- H2 Test Event AP：96.7597%。
- H2-plus Test Event AP：96.9309%，比 H2 高 0.1712 个百分点。
- EV-SpSegNet 原论文没有报告 Event AP 或 mAP，图中明确标为未报告，不做推算。

Validation 图使用相同版式。EV-UAV 原论文没有公开 EV-SpSegNet 的 Validation ACC、Pd 或 AP，因此相应位置保留为“未报告”，没有用 Test 数值代替。H2 Validation Event AP 为 96.1001%，H2-plus 为 96.1385%，H2-plus 高 0.0385 个百分点；ACC 和 Pd 分别为 90.9489%/90.0252% 与 91.2970%/90.3192%。
