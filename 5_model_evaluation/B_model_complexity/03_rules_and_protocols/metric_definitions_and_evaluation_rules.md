# B 类模型复杂度标准 v2

比较冻结的相同评分前缀，注明位宽、数值路径和条件路由。旧整数计数保留，不重新解释为硬件实测。

| 编号 | 定义 |
| --- | --- |
| B01 参数量 | 正式权重参数元素数，包含零权重，区分参数与非参数 buffer。 |
| B02 静态存储 | 权重、尺度和固定推理 buffer 的 tensor payload 字节；不是压缩文件大小，不含可变运行状态。 |
| B03 结构连接 MAC | 对实际触发的前向调用按完整连接计数；稀疏卷积为活跃输出位置×核连接，不是所有路由均执行的全网稠密上界。 |
| B04a 非零有效 MAC（理论） | 非零输入和非零权重对应的连接操作量，不证明执行后端实际跳零。 |
| B04b 脉冲突触 AC（理论） | 实际脉冲及连接对应的累加量；普通 ANN 的突触 AC 按架构为 0，神经元状态更新另列。 |
| B04c MAC+AC 未加权计数 | 各计 1 次，仅作组成诊断，不能作为跨位宽/架构的成本、速度或能耗主排名。 |
| B05 持久状态内存 | 跨窗口/时间步保留的历史特征、膜电位等总字节；与权重和临时工作区分开。 |

H2/H2-pro B03/B04 只计 Proposal 与条件 Refiner，Proposal 不重复计；不含特征构建、路由、后处理、状态更新和存储访问。当前 NumPy dense matmul 未证明理论非零量减少了实际执行成本。跳零收益需另附实现/计数器/追踪，能耗以 C05 为准。加权成本须使用同设备/精度实测权重，与 B04 分开。

B01/B02/B05 保存于 common；B03/B04 对每个划分全部 24 条序列等权平均，保留逐序列操作数、闭合窗数、候选事件数。MAC/FLOP/AC 不混用；不同输入长度/事件量披露分母，只有同范围可直接比。

B05 源为 common/state_memory.json，协议 persistent-state-inventory-v2，附总标准的 v2 身份/证据字段。summary.persistent_state_bytes 必须等于 state_inventory 各项 bytes 之和；每项含 name、shape、dtype、bytes、容量与生命周期，清单/导出日志作为哈希证据。动态状态固定容量或给最大合法输入下上限；零状态也提供显式清单与依据。

旧 H2-pro persistent_proposal_history_bytes=11968 只是一个分量，不自动回填 B05 总量；B02=12912 字节也不是总运行内存。RSS、设备缓冲/CMA 峰值归 C08，清单缺失则 B05 pending。EV-SpSegNet 论文约数保留 paper_reported，等待同范围模型导出/统计。
