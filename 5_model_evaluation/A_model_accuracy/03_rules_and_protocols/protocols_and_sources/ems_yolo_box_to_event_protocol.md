# EMS-YOLO 框到事件正式评测协议

## 适用模型

- `evaluation_id`: `EMS-YOLO`
- 模型：在 EV-UAV 上训练的改进版 EMS-YOLO SNN
- 数值路径：FP32、CUDA、5 个时间步
- 冻结阈值：0.407

阈值 0.407 来自正式准入前实验报告中的 Validation F1 峰值。正式补测不得再次用 Validation 或 Test 调阈值。由于阈值曾依据 Validation 选择，Validation 结果属于选择相关结果，Test 是主要无偏横向比较。

## 250 ms 检测框到逐事件概率

模型原始预处理使用 250 ms 窗、100 ms 步长，每个窗口含 5 个时间步。正式评测直接从原始 EV-UAV 序列生成完整滑窗，并在 320×256 坐标系输出 NMS 后目标框。旧预处理只保存含目标标签且事件量超过门槛的窗口；正式评测禁止这种 GT 选择，以免遗漏背景 FP。

对每个原始 304×240 事件：

1. 从首事件时间开始，以 100 ms 步长生成所有 250 ms 左闭右开窗口，直至覆盖末事件；尾窗事件范围外保持中性像素；
2. 只用归一化坐标、时间和极性生成 5×240×304×3 输入，再按原 `val.py` 双线性缩放到 5×256×320×3；
3. 对每个事件检查所有覆盖它的滑窗，取所有覆盖框中的最大置信度；
4. 未被任何框覆盖时概率为 0。

输入窗口选择和预测生成过程不得读取事件 `label` 或 `name`，不得因目标缺失或事件量低而跳过窗口。适配后概率与原始事件严格一一对应，A01–A13 复用统一事件协议，A14–A22 复用冻结的 50 ms 可观测事件轨迹 HOTA 协议。

## 解释边界

该结果评价“EMS-YOLO + 固定框到事件适配器”，不是原生逐事件分类器。实验报告中的框级 `mAP@0.5` 不能替代 A01 Event AP；两者可以分别保留，但不得在同一指标列中混用。

## 复杂度同步测量

同一次完整序列滑窗前向统计 Conv2d/Linear 的 B03、B04a、B04b：全部结构连接计稠密 MAC；非零模拟输入连接计有效 MAC；二值脉冲输入连接计有效 AC。`B04c = B04a + B04b`。NMS、数据加载、事件帧生成和框到事件适配器不计入网络算子复杂度。
