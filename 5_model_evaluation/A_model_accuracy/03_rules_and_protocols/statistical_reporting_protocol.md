# 汇总与不确定性

Event AP 按相同分数分组，使用阶梯积分 Σ(Recall_i−Recall_(i−1))×Precision_i，非梯形积分或框 mAP；包含全部评分事件及路由拒绝事件的冻结分数。IoU/Precision/Recall/F1 先汇总 TP/FP/FN，再求比率。A08 为序列 Recall 等权平均；无目标序列记 null，并报告排除数。A09/A10 以完整原始序列事件率≥20000 events/s 分组，组内汇总计数；报告序列数、事件数、目标数。空分组不填 0。

A04 主名 Target-event Recall，ACC 仅为论文别名。F1=2IoU/(1+IoU)，不能把两者提升算作独立证据。原始比率为 0–1；百分数及差值百分点显示均乘 100，不混用相对百分比。

HOTA 在固定 19 个 IoU 门限计算后平均；跨序列用原始匹配计数和权重合并，不平均各序列 HOTA。A22 每条 GT 轨迹取最长连续可观测漏检时长，再对轨迹取线性插值 P95；无 GT 时 null。静默窗不补框，不能声称持续跟踪静默物理目标。

## 区间与配对差值

主要 AP/IoU/Recall/HOTA 应报告 95% 区间及模型间配对差值。以序列为单位，在高/普通密度层内配对重采样，预先固定 10000 次及种子；同一抽样用于候选和基线，重新合并原始计数/概率/轨迹统计。不得把同序列事件当独立样本，也不得平均序列 AP/HOTA 代替总体值。

记录 metric、split、evaluation_id、reference_evaluation_id、point/delta、ci95_lower/upper、样本数、seed、repeats、method、scope 与来源哈希。绝对区间和配对差值区间分开；差值区间跨 0 时不宣称稳定提升；不能据 Test 区间重新选模型。多指标探索需声明，不能让相关指标重复投票。

## 应用可选项

不改变当前 A01–A22 编号；以下需先冻结定义再启用：

- 首次检出延迟：首次可观测 GT 事件到首个满足固定匹配条件的输出。完全未检出轨迹单报漏检率/右删失，不能只保留成功样本。
- 目标级虚警/分钟：固定关联器和跨窗去重，同一持续虚警轨迹计一次报警；按有效观测分钟归一化，不能由像素 Fa 直接换算。
- 高密度、突发、小目标、长期运行及外部数据集分组/压力测试：预先固定样本与负载，不混入主数据集排名。

验收前指定主指标及约束，例如 IoU/AP、目标 Recall、虚警、延迟截止、内存/功率预算；不把 A/B/C 未约定加权成一个分数。
