# Paired uncertainty

paired_iou_delta.csv exposes existing H2-pro minus H2 sequence-level paired bootstrap intervals. Units are fractional differences (multiply by 100 for percentage points). These are difference intervals, not absolute-score confidence intervals. H2 remains a noncausal historical reference. Other metric intervals remain pending. See the [statistical protocol](../../03_rules_and_protocols/statistical_reporting_protocol.md).
