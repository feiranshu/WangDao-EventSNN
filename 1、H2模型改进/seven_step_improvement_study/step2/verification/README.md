## 验证结果

1. Python语法检查：`run_step2.py`、`step2_common.py`、`step2_training.py`、`step2_audit.py`、`collect_step2_results.py`全部通过。
2. 步骤二单元测试：8/8通过，覆盖固定分层采样比例与确定性、32维特征组划分、A2-2加权损失、A2-4-null等价损失、STC局部支持权重、“无合格工作点”时的安全诊断导出、逐轮进度持久化，以及续训检查点和命令行契约。
3. 数据预检：通过；79条Train-main、10条Train-dev；未读取Validation/Test；H2权重和数据索引哈希已记录在`local_preflight.json`。
4. 真实数据CPU冒烟：完成；实际走通候选缓存、特征审计、STC适用性诊断、A2-1/A2-2单步训练、检查点选择和指标导出。小样本审计跳过A2-3、STC诊断跳过A2-4；这只说明门控生效，不作为正式候选结论。精简决策见`smoke_pipeline_summary.json`。
5. 原H2回归测试：42/43通过。唯一失败来自冻结基线`h2_students.py`在本机PyTorch 1.9.1中调用较新版本才支持的`torch.load(weights_only=...)`，与步骤二改动无关，因此没有修改冻结基线。
6. 服务器ZIP：只保留步骤二实际依赖闭包，完整反向解压并逐文件校验27个清单项；ZIP内目录权限固定为`755`、普通文件为`644`、`run_server.sh`为`755`，并逐项验证Unix权限元数据；在解压副本中再次完成语法检查和步骤二8项单元测试。
7. 结果收集器：临时运行目录打包测试通过，确认`step2_decision.json`和`.pt`检查点会进入回传ZIP，候选缓存不会进入。
