## 1. 冻结锚点、目标与决策原则

### 1.1 唯一正式 ANN 锚点

唯一正式 ANN 基线为 **H2-pro-Causal-ANN-v1**：C1-proposal-motion、seed42、epoch10、exact-int8、分类阈值 0.35，采用 100 ms 闭合窗口。权重、索引、特征协议、候选发布规则和评价范围均保持冻结。新增的小型 ANN 是研究对照，不能替换这一锚点。冻结证据见 [`final_H2-pro/deployment_decision.json`](../1_H2_model_improvement/implementation/results/final_H2-pro/deployment_decision.json) 与 [`H2-pro/FINAL_REPORT.md`](../1_H2_model_improvement/seven_step_improvement_study/H2-pro/reports/FINAL_REPORT.md)。

| 冻结指标 | Validation | Test |
| --- | ---: | ---: |
| Event IoU | 87.8318% | 87.1383% |
| Recall | 92.1671% | 94.2947% |
| 高密度 Recall | 51.8782% | 76.8746% |

现有 Train-dev 闭合前缀诊断：Proposal 目标事件召回为 **98.42%**；总漏检 **4,322** 个，其中 Proposal 导致 **478** 个，已进入候选集合后由 Refiner 导致 **3,844** 个。因此先研究 Refiner。上述计数不能证明漏检是由跨栅格记忆、亚阈值状态或背景积累造成；这些属于后续待证伪的假设。

### 1.2 研究目标与边界

- 首要目标：在同一任务及可比较的输入期限下，使最终 SNN 精度争取不低于冻结 H2-pro，并显著减少整条推理链的计算。
- 进取工程目标：整网有效 MAC 约降低 90%、MAC+AC 约降低 50%、观察等待达到 10 ms 级。它们尚未被证实可达，不作为早期 Refiner 机制的机械淘汰线。
- 当前研究浮点 SNN、ANN 对照、时空状态、知识迁移、流式执行以及运算和状态成本。RTL、FPGA/ASIC、量化、PoT、LOA 与硬件能耗实测不进入本轮默认链。
- 已有旧 SNN 研究不支持“目标位置普遍不发放”的先验判断，旧膜电位读出搜索也未通过升级条件。新研究只复用其可信诊断，不重启同一大搜索。
- 冻结 Proposal 优先保持原样；Proposal 时间协议与计算改造放在 S6。不能通过把大量非候选事件送入昂贵 Refiner 来假定弥补误筛。

### 1.3 每阶段的决策记录

S0–S9 各阶段结束必须保存一张决策卡：**本阶段假设、预注册的主要变化、训练与输入预算、整体及目标子集结果、计算/状态/延迟、支持与反驳的解释、继续/修改/停止结论、下一阶段实验和预算**。对每个研究机制，最多允许两轮有诊断依据的主要假设修订；实现错误修复不计入这两轮。未达到机制入口条件时跳过相应阶段，不为完成计划而强行训练模块。

### 1.4 S2 后审查：已成立的结论与计划变更

完整审查见 [`reviews/S2_REVIEW.md`](reviews/S2_REVIEW.md)，基于 S0/S1/S2 原始结果、训练实现、7 项测试复核，以及现有 epoch5 检查点的逐事件只读回放。S2 结果与协议保留原样，本节更新后续执行顺序。

- **S2 完成的是健康检查。** 研究 ANN 的 Train-dev IoU/AP 为 0.7029/0.8899，SNN 为 0.6339/0.8105，分别采用预设网格选择的 0.55/0.60 阈值。H2-pro 同一 Train-dev 的历史 IoU/AP 为 0.7926/0.9340。SNN 第 4→5 轮 AP 仍从 0.7972 升至 0.8105，尚不能判断充分训练后的能力。
- **先补训练可比性。** ANN 使用加权 CE 的权重和归一化，SNN 使用事件数归一化；相同类别权重不代表相同梯度尺度。S3 统一目标函数分母、记录实际更新次数与样本组成后再建结构对照。S2 的健康检查结论有效，但旧训练损失不可直接横向比较。
- **优先研究状态负担与状态价值。** 逐事件回放发现普通/高密度序列的输出层在复位后仍超过阈值的更新占比分别为 31.61%/41.29%。这支持状态分解，尚不证明其造成误报。原健康报告仅采样窗口末持久状态的绝对极值，不代表完整逐事件极值。
- **首次出现/再现改用相同误报预算比较。** SNN 子集召回更高伴随更多整体 FP；不能据此确认记忆有效。对齐 FP 预算后，再通过同预算重训的状态保留/窗口重置对照确认作用。
- **S4-S、S4-B 继续关闭。** S1 跨格与局部背景关联受少数高密度序列主导；S2 没有消除这些混杂因素。BPI 不因输出发放高而自动晋级。
- **GPU 优化成为条件工程任务。** 现有 CPU 实现可支持有限诊断和短程对照。长程训练前根据实测耗时决定是否迁移 GPU，不将“先完成 GPU 批量执行”设为开始 S3 的硬前提。

后续顺序明确为：**S3-A 只读分解 → S3-B 训练口径统一与参考训练 → S3-C 状态对照 → S3-D 必要的单点动力学修订 → S3-E 机制入口复核**。表示删改和空间地址变更降为条件项，S4–S9 主线保留。

## 2. 共用 Refiner 与时间协议

### 2.1 固定位置参考网络

先建立同输入、相近容量的两条研究对照：

```text
冻结 H2-pro Proposal（100 ms 闭合候选）
        │
        ├─ 研究 ANN：36 → 48 → 32 → 4
        │
        └─ 研究 SNN：36 → 48 LIF → 32 LIF → 4 LIF
                                      ↓
                          脉冲轨迹 + 残余膜电位读出
```

冻结 H2-pro 原 Refiner 为 `36→64→32→4`，是正式精度锚点，不与 `36→48→32→4` 对照混称“同容量”。初期保持 36 维候选特征与候选集合一致，再分别研究输入、空间状态或传播；不能一次改动特征、网格和横向机制。

| 参考实现项目 | 初始约定 |
| --- | --- |
| 空间地址 | 三层 LIF 都按事件的 4×4 像素位置寻址，同址前馈；输出层同样保留空间状态 |
| Refiner 网格 | 真实传感器 346×260 对应 87×65 个有效单元，边缘单元只含有效像素 |
| Proposal 网格 | 保留冻结实现使用的 88×68 填充布局，两种网格的存储账目分开计算 |
| 第一层时间常数 | 48 通道分为三组，每组 16 通道，初始 τ 为 5/25/100 ms |
| 第二层、输出层时间常数 | 初始分别为 25 ms、100 ms；后续调整单独做受控实验 |
| 状态动力学 | 真实时间差指数衰减、阈值发放、soft reset；每次状态更新至多发一个二值脉冲 |
| 状态生命周期 | 跨 100 ms 窗口保留；序列开始、重放与切换时清零；空闲时惰性衰减到下一次被访问时刻 |
| 输出语义 | 四个原型，目标/背景各两个；同一类别用固定的两原型聚合规则，ANN/SNN 对照统一 |
| 初始读出 | 每个原型的脉冲衰减轨迹与归一化残余膜电位作可学习线性组合，再聚合为类别分数；读出乘法计入成本 |
| 初始训练截断 | 每 100 ms 截断梯度，数值状态继续传递，不在截断点重置；完整序列依原时间顺序训练/回放 |

按 65×87 有效单元、FP32 计算，第一层 48 通道膜电位为 **1,085,760 B，约 1.04 MiB**；三层 48+32+4 通道膜电位及四通道读出轨迹合计 **1,990,560 B，约 1.90 MiB**。此外分别计时间戳、候选元数据、路由、内部队列与训练缓存，不能以首层存储代表全网。

初始优化采用 FP32、AdamW、梯度裁剪与替代梯度；具体学习率等在 S2 参考骨架的 Train-dev 健康检查中定一次并记录，后续结构对照使用同一搜索预算。先建立标签监督模型，再单独比较知识蒸馏，最后加入计算约束。冻结 H2-pro 教师可提供离线训练监督，不能将它使用的后验特征输入严格逐事件推理。

S2 已将实现细节记录在 [`s2/PROTOCOL.md`](s2/PROTOCOL.md)：神经元阈值 0.5、三角替代梯度、类内两原型取最大；初始化修订后的权重倍率为 1.0/0.65/0.35，读出增益初值为 0.25。它们是 S3 的参照设置，不是最终设计。S3 起损失归一化按 4.1 节统一；涉及训练目标或状态规则的新结果使用新编号，不覆盖 S2。

### 2.2 必须分开的两种时间协议

**协议 A：闭合窗口 SNN。** S1–S5 默认采用冻结 Proposal 的 100 ms 闭合候选与 36 维特征，再按事件时间戳回放 Refiner。部分特征使用已完成的当前时间桶统计，因此这种回放只证明闭合窗口后的时序状态效果；结果在窗口闭合前不能发布。

**协议 B：严格事件因果 SNN。** S6 才进入。候选判断、输入特征、Refiner 更新和输出都只能使用所报决策期限之前的数据。10 ms 微批发布和逐事件发布分别命名、比较。固定 10 ms 切片也可以在切片内执行多个内部更新；逐事件调度的潜在价值在物理时间定义与按活动更新，不能将“可以多跳”当作其独占优势。

接口统一为 `reset / push / flush_completed_windows / finalize`。每条输出至少包含事件索引、传感器事件时间、可发布时间、候选标志、概率与预测类别；运行元数据记录观察协议、状态模型和成本计数。空窗口、尾部未闭合窗口、序列重置和静默期必须有明确结果规则。

## 3. 三条有条件的机制路线

### 3.1 S4-S：空间传播的最小可证伪实验

空间传播只在 S1/S3 发现有样本量、可重复、控制密度等混杂因素后仍成立的跨空间信息利用不足时启动。S1 可先做 ANN 错误分组；源端膜电位、源端脉冲、目的端状态与错误变化，只能在 S2 训练出可信 SNN 后诊断。

传播**载体**、**路由**、**跳数**、**外部输入调度**是四个独立变量。初版先固定同一个局部邻域与路由，逐项改变一个因素；不展开四维全组合实验。

**MRR：运动关联的连续残余迁移。** 单条 A→B 路由先将两端同一时间常数组的状态衰减到共同物理时刻，再执行：

```text
r = α · g(A→B,t) · ū_A
u'_A = ū_A − r
u^-_B = ū_B + r + I_B(t)
```

其中 `0 ≤ αg ≤ 1`，初版只选单源或空路由与一跳，再判断目的端是否发放。MRR 能在源端未发放时利用其亚阈值历史；初始定义同时从源端扣去迁移量。另设**复制而不扣源端**的对照，避免将“连续载体”和“源端扣减”的作用混为一谈。状态转移账目不构成天然稳定或抗噪的证明。

**MRU：源脉冲触发的同层横向递归。** 研究暂用名，不声称它是首次提出的标准算法。第一隐藏层源位置发放后，生成目的邻居的突触消息：

```text
I_lat,B(t + δ) = w_BA · g(A→B,t) · s_A(t)
```

目的端积分后若再次发放，才可能形成下一跳。源端正常执行 soft reset，不因发送横向消息额外扣减膜电位。初版使用二值脉冲、固定局部连接；多跳实验采用 **1 ms 正突触延迟、最多两跳**，一跳实验采用相同延迟。可学习延迟、动态扇出、不应期、多跳 MRR 均延后，除非一跳诊断指向它们。

MRR 与 MRU 不仅传播载体不同，触发条件及源端处理也不同。两者直接比较仅能比较整体机制；要把改善归因于亚阈值状态、方向路由、扣减或多跳，必须通过相应对照。两者都可以定向和多跳，不能把这两项能力写为 MRU 独有创新。

| 子实验 | 入口 | 需要回答的问题 |
| --- | --- | --- |
| SP-0 固定位置 LIF | S2 的可信模型 | 无横向传播的参照 |
| SP-1 局部一跳脉冲通信 | 跨空间失效有证据 | 最简单的邻域通信能否修复相关错误 |
| SP-2 一跳 MRR | 残余历史可能滞留，或 SP-1 后仍有相关错误 | 连续状态通路是否有额外收益 |
| SP-2C 复制不扣源端 | SP-2 获得积极结果 | 收益是否依赖源端扣减 |
| SP-R 方向与打乱路由 | 传播有效且拟提出运动路由主张 | 定向运动信息是否有独立价值 |
| SP-3 两跳 MRU | 一跳有效且远邻仍有错误 | 多一跳是否值得增加的工作量 |
| SP-A 局部递归 ANN 强对照 | 任一传播候选进入 S5 | 普通空间递归能否解释相同改善 |

初始新增训练只包括 SP-1、SP-2；其余按入口追加。SP-A 默认用感受野和状态预算相近的局部递归 ANN；只有门控记忆构成关键解释时再加 ConvGRU。无法同时精确匹配参数、状态、感受野、观察期限与运算时，明确固定条件，并给出精度—成本曲线，不声称已经“全维度公平”。

停止与降级：一跳无可信收益则不做多跳；多跳无独立收益则退回一跳；打乱方向仍保持收益则撤回运动路由主张；复制与迁移相当则不能宣称扣减是核心；普通递归 ANN 在相近预算下同样有效则重新检验 SNN 特有贡献；源端损失、背景误发放或路由/队列/访存抵消节省时缩减或停止路线。任一提升只出现在更长观察期限或闭合窗口后验信息下，必须按真实协议表述。

### 3.2 S4-B：背景可预测活动补偿

只有当 S3 显示可预测背景活动与不良状态积累有关，且简单密度差异不足以解释时启动。依序比较普通 LIF、密度归一化或阈值调节、历史均值补偿；前者有不足且证据充分时才考虑动态补偿。候选形式为 `du = −u/τ·dt + Σw(dN − λ̂·dt) − θ·dS`，`λ̂` 仅依赖决策时刻前可用的活动统计。检查慢目标被背景模型吸收、相机运动背景和净计算成本。不增设昂贵背景 MLP，不硬删除事件。MRU 出现活动爆发不能自动成为启动 BPI 的依据。

### 3.3 学术贡献的最低证据

潜在主张只在实验后择一确定：

1. **运动关联亚阈值迁移**：证明有价值的残余历史留在源端，且 MRR 相对脉冲、复制、打乱路由与适当 ANN 对照具有独立、可重复的精度—成本收益。
2. **受限横向脉冲传播的条件计算**：分离一跳/多跳贡献，在相同输入期限下相对普通空间递归获得有意义的精度—成本优势，且无不可接受的内部脉冲爆发。
3. **背景可预测活动补偿**：证明补偿解决诊断出的状态积累问题，并优于简单密度归一化与阈值调整，且不系统性损伤慢目标。

已有 [LISNN（IJCAI 2020）](https://www.ijcai.org/proceedings/2020/211) 研究同层邻域交互，[TrajGRU（NeurIPS 2017）](https://proceedings.neurips.cc/paper_files/paper/2017/hash/a6db4ed04f1621a119799fd3d7545d3d-Abstract.html) 研究运动相关状态连接，[AMP²（AAAI 2026）](https://ojs.aaai.org/index.php/AAAI/article/view/37187) 涉及脉冲网络中的激活传播。因此“横向传播首次提出”“多跳首次提出”“SNN 天然省计算”都不能成为预设贡献。写论文前继续核对最接近的正式论文，按实验证据缩小新颖性主张；目前不保证存在从未发表的决定性机制，也不保证 CCF A 类录用。

## 4. 分阶段执行路线

| 阶段 | 主要交付 | 进入下一阶段的决策 |
| --- | --- | --- |
| **S0 冻结契约** | 核对 H2-pro 权重、阈值、索引、输入/输出协议、历史错误和 B03/B04 成本；建立第二代实验编号与记录入口 | 只重用可信的旧证据，不重跑整套历史研究 |
| **S1 错误分组** | 在 ANN 候选内按跨 4×4 单元、首次出现、短暂中断/再现、方向/速度变化、背景密度统计假阴性；匹配密度及候选分布 | 形成可证伪假设；不提前测尚不存在的 SNN 内部变量 |
| **S2 统一骨架** | 训练研究 ANN 与无横向传播 SNN；验证状态、读出、梯度、发放、真实时间衰减及运算账本 | 数值或训练不健康先修复；5 epoch 仅作健康检查，必要时延至 10 epoch |
| **S3 训练与状态分解** | 先统一训练口径，分层诊断状态、读出和 FP；建立训练充分度与保留/重置对照；表示与网格按证据启动 | 按 4.1 节逐步确认，不能从有限数值或更高子集 Recall 直接启动 S4 |
| **S4-S 空间传播** | 按 SP-0/1/2 条件推进复制、方向和多跳消融 | 保留能解释收益且成本可接受的最简机制 |
| **S4-B 背景补偿** | 按普通 LIF→简单归一化/阈值→均值补偿逐级比较 | 无独立收益即停止，不与传播路线自动合并 |
| **S5 核心确认** | 至多两个候选及关键强对照，三种子、序列配对分析、负面结果 | 核心贡献由结果决定，不能靠短跑 IoU 指定 |
| **S6 前端时间路线** | 固定所选 Refiner，筛查原 100/100、100 历史/10 发布、10/10 ANN、10 ms 状态 SNN、严格逐事件 SNN | 仅最有价值的两条进入完整训练；窗口改变时重训匹配学生 |
| **S7 组合与压缩** | 只组合各自有效的模块；独立检验蒸馏、输入乘法、活动控制和压缩 | 每次证明组合的增量收益，冲突时保留简单方案 |
| **S8 外部验证** | 按已确认机制选择一个外部数据集，先审查标注粒度、切分与任务可比性 | 在外部测试前冻结迁移协议；不把框内事件等同像素级真值 |
| **S9 最终冻结** | 冻结权重、阈值、输入、状态、截止时间及成本实现，完成保留集验收 | 如实报告达到与未达到的精度、计算、等待目标 |

S6 中的 `100/100` 表示 100 ms 历史与 100 ms 发布；其余写法同理。100 ms 历史/10 ms 发布方案必须验证事件加入及到期移除的增量实现与完整重算一致。原 H2-pro 特征构造已经利用窗口内全部原始事件；“所有事件先写昂贵共享神经网络状态”不作为必须新增的项目。新前端直接沿用旧权重失败，也不能替代同预算重训后的路线判断。

### 4.1 S3 的执行顺序、预算与结果分支（S2 后修订）

**S3-A：只读诊断，新增训练 0 epoch。** 使用现有 ANN/SNN epoch5 检查点、Train-dev 10 序列和固定的 Train-main 诊断子集，不读取保留集。先复用本次审查的逐事件统计，再补缺项：

1. 按序列、普通/高密度、目标/背景、每层及每个输出原型，记录带符号的膜电位分布、复位后仍达阈值的比例、连续发放、替代梯度支撑区间覆盖、原型获胜比例、轨迹/残余读出贡献，以及 TP/FP/FN 的对应情况。输出层包括背景原型，发放高不等于目标误报；脉冲分支局部梯度为零也不等于整个网络梯度为零。
2. 按同一组预测建立完整 PR 曲线。以研究 ANN 已记录的全局 FP=4,137 为主要诊断预算，以冻结 H2-pro 的 FP=2,463 为补充预算；选择不超过预算的实际阈值点，离散分数并列时报告实际 FP，不插值伪造分类结果。比较首次出现、再现和跨格的候选内 FN，并同时报告普通/高密度 FP。这里使用标签选择的工作点属于开发集诊断，不是新冻结阈值。
3. 对同一 SNN 检查点做窗口重置、逐层状态移除、轨迹/残余读出屏蔽等推理干预，先定位敏感组件。这些干预造成分布变化，仅用于决定下一项重训实验，不能作为某种状态设计优劣的最终证明。
4. 检查 36 维累计特征在同格多个候选上反复注入后，局部事件率、累计输入电流与有符号状态/错误是否关联。不能仅凭高密度猜测“重复积分”成立，也不直接改成原始事件输入。

**S3-B：统一训练口径并建立可信参考。** 新建 S3 协议与运行目录，保留 S2。两模型统一使用 `sum(w[y] × CE) / sum(w[y])`，权重暂保留背景 1、目标 3；报告全序列无权 CE，以及按全序列权重和统一归一化的加权 CE。按相同的 8 个非空 100 ms 窗口组成梯度更新组，ANN 使用相同候选集合，SNN 仍每窗口截断梯度、保留数值状态。记录每轮样本暴露量、更新次数、裁剪比例、状态重置与初始化。学习率先保留 S2 已记录的 ANN 1e-3、SNN 5e-4；不同优化设置明确披露，不将修订前后的差异单独归因于结构。

首轮仅训练 ANN 参考与持久状态 SNN 两个模型，seed42，从对应 S2 修订后的初始化规则重新开始，预定检查点为 epoch5、epoch10。原检查点用于只读分解，不把改变训练目标后的接续运行称为原 S2 的等协议续训。10 epoch 是下一次决策节点；健康而仍持续改善的候选需在统一的 30 epoch 预算下比较后才能作能力淘汰。数值/状态明显失控时先诊断，不盲目延长训练。

**S3-C：状态价值的最小重训对照。** S3-B 有可信参考后，仅增加一个“每个 100 ms 窗口开始重置神经元与轨迹状态”的 SNN，其他训练协议、初始化、候选与输入特征完全相同，预算与持久状态参考对齐。当前输入特征自身仍包含历史，该对照检验的是额外神经元跨窗口状态，不得称为移除了全部时间信息。采用 S3-A 的相同 FP 预算及完整 PR/AP 比较，并检查普通/高密度、首次出现与再现的配对错误。

- 保留状态在相同 FP 预算下稳定改善相关错误：保留状态，继续分析未解决的空间或背景问题。
- 重置状态改善整体及相关子集且减少状态异常：先定位有害累积层，不引入横向传播；不得据此否定所有时间状态。
- 两者接近或序列间方向不一致：记忆效用未确认，采用较简单参考并停止扩展长时记忆模块。

**S3-D：按诊断选一个动力学修订。** 仅当 S3-A/C 指向明确问题时启动，首轮最多一个新增结构，并重训匹配预算。如果正向复位后余量与错误/连续发放关联，先在被定位的一层比较 soft reset 与 hard reset；如果主要是读出或输入注入，则只修改被定位的一项。不要同时改变重置、阈值、时间常数、读出和输入表示。负电位幅度大、输出背景原型发放高或替代梯度局部为零，均不足以单独触发改动。每项修订均须同时检查整体 AP/IoU、同 FP 预算召回、首次出现/再现以及运算与状态成本。证据不足就停止该子步骤，不做神经元参数大搜索。

**S3-E：重新审查 S4 入口。** 空间传播需在已解决训练/状态可比性问题的模型上，证明跨格相关的错误仍存在，且有源端可用信息未被目的端利用的状态证据。BPI 需证明背景可预测活动与不良状态有关，且简单重置/归一化或阈值变化不足以解释。若现象只针对高密度，可在 Train-main 中按完整独立序列预先划出机制诊断子集；确认模型不得训练这些序列，并且不改动原正式五角色划分。高密度专属机制不必强求在普通密度同样改善，但不能只凭现有两条高密度 Train-dev 序列宣称一般规律。两项入口仍不成立时，保留可靠 SNN 参考并更新假设，不自动执行 SP-1/SP-2 或 BPI。

**计算实现为并行的条件工程项。** 先测每窗口填充槽位/有效候选比、每步主机/设备拷贝与同步、各层/读出耗时，补齐 Refiner 的残余读出 MAC 和状态标量账目。当前只把 8 次读出乘法另列，不能将 480,882,096 个输入 MAC 标作 SNN 全部多值运算。需要 GPU 时，先验证预测、状态、损失、梯度及一步更新的一致性；空间单元独立时的并行调度不能直接沿用到将来的横向耦合网络。仅在实际运行预算构成瓶颈时实施加速，允许 CPU 完成有界诊断与短程参考训练。

S3 新运行使用已预留的 `GEN2-S3-001` 起始编号及新的追加记录；本次文档审查和检查点重放不是 S3 训练完成。S3 首轮重训最多三条（ANN、持久状态 SNN、条件执行的窗口重置 SNN）；动力学修订需先有决策卡。空间地址变更、特征删改、KD、活动惩罚和 Proposal 改造不与这三条基础对照叠加。

## 5. 训练、评测与验收纪律

### 5.1 数据与预算

- Train-main **79** 序列仅用于训练；Train-dev **10** 序列用于诊断、选择和阈值；HW-calibration **10** 序列不参与本轮浮点选型。
- Validation **24** 序列在候选和协议冻结后运行一次；Test **24** 序列仅用于最终冻结验收。二者历史数值可引用，但不能反向用于新增结构、阈值或时间常数选择。
- 初筛使用 seed42；进入 S5 的候选及关键对照使用 seed42/43/44，并统一 30 epoch 预算。5 epoch 健康检查不按 IoU 高低淘汰训练健康的机制。
- 高密度沿用序列事件率 `≥20,000 events/s`；Train-dev 只有少数高密度序列时，不把不稳定区间解释为充分泛化证据。
- 按序列进行配对误差分析与密度分层 bootstrap，报告三种子差异。区间跨零属于证据不足；“未检出下降”不等于证明精度没有下降。
- S3 起统一训练损失的归一化定义，并报告实际优化步数。阈值规则在新运行前固定为 0.05–0.95、步长 0.05，包含原 0.35；按整体 IoU 最大、同分高密度 Recall 更高、再同分阈值更低选择。报告完整曲线、AP 和同 FP 预算诊断，不追认 S2 的事后 0.75 为预注册结果。触及新网格边界时记为校准待定，不根据结果反复扩展网格。

### 5.2 精度、计算与等待

精度同时报告 Event IoU、AP、Precision、Recall、Proposal 目标召回、候选比例、Refiner 条件召回及高密度 Recall。整网指标必须包含被 Proposal 拒绝的事件；只报候选内部指标会高估最终效果。正式结果以同一输入期限与同一数据索引为前提。

运算分别报告：稠密网络 MAC；规定跳零假设下的有效 MAC 与二值 AC；状态衰减、路由、比较、输出读出等标量操作；状态常驻字节、读写及队列；实际运行时间。多值输入和多值突触不能计成一次二值 AC。首层 `36→48` 的稠密工作为 **1,728 MAC/候选事件**；冻结 Proposal 约为 **2,580,480 稠密 MAC/100 ms**。因此仅替换 Refiner 时，不以“整网 MAC 降低 90%”作为早期机制淘汰线。旧 B04 有效 MAC 是跳零规则下的计数，不等于 CPU/PyTorch 实际执行次数，也不等于能耗。

空间传播额外记录内部脉冲/外部候选比例、单次触发的状态更新数、平均/p95/最大跳数、队列峰值与积压、各层读写、源端及目的端错误变化。分别报告事件观察等待、计算耗时和队列延迟；闭合窗口后的时间戳回放不能写为 10 ms 端到端观察延迟。

### 5.3 流式执行与验证场景

MRU 的内部消息采用确定的时间调度：相同时间戳先处理已经到期的内部消息，再按原始事件索引处理外部事件；空闲期间由水位线继续推进已排队消息。事件预测在该事件的规定前馈更新后读取；之后到达的横向消息只影响后续状态，不回写旧预测。传播消息携带深度，超过初始两跳上限不继续横向发送。上限是实验模型约束，不是动力学自然稳定的证据。过载不得静默丢弃消息；标记该次实验不合格并报告队列与活动峰值。`finalize` 只推进到预定终止时刻，之后到达的消息不参与评分。

每种实现必须覆盖以下验证：

1. 闭合窗口前缀一致性；严格逐事件模型还需逐事件前缀一致性。不同输入分块在数学上等价时结果相同。
2. 同时间戳、同格多事件、传感器边缘、空窗口、长静默、跨窗口、尾部不足完整窗口及序列重置。
3. MRR 源端扣减和目的端增加的账目；关闭迁移后与参考模型一致。
4. MRU 源端未发放时不产生横向脉冲；一跳、两跳、空闲传播、截止时间及活动上限符合定义。
5. 优化执行与逐事件参考执行一致。时间分桶若改变数学结果，必须作为另一个近似模型报告。
6. 在小型可手算序列上核对 MAC、AC、内部消息、状态读写和实际输出时刻。

### 5.4 停止边界与最终成果

全事件可学习共享记忆、Proposal 漏筛恢复分支、SCU 独立创新线、大规模读出搜索、全组合网格搜索、多跳 MRR 以及 MRR/MRU/BPI 的预先组合均不进入默认执行链。若空间传播与背景补偿都缺乏证据，返回 S1/S3 更新错误假设，不能通过不断叠加模块维护预定论文叙事。

最终交付应包括冻结 SNN、可重放协议、精度—计算—状态—延迟账本、强对照与负面结果，以及经最接近文献核查和实验支持的一项核心机制结论。第二代代码、实验和结果使用新的目录/编号；第一代材料保留在 [`old-version/`](old-version/) 中。论文主张与发表层级以最终证据为准。
