# MLP 到 SNN 转换与近似计算研究计划

## 1. 边界

第 1 部分负责提高 ANN 准确性；本部分负责把冻结 ANN 逐级转换为 SNN，并研究定点、PoT、近似加法、可部署数值契约及模型选型。RTL、Vivado、KV260 位流和板端执行归第 4 部分。

数据角色保持不变：Train-main 用于训练，Train-dev 用于选择，HW-calibration 用于位宽和近似规则，Validation 仅在阶段冻结后运行，Test 只用于最终验收。

## 2. 第一代已完成工作

1. 浮点转换：完成 S0-P、S0-R 和 S0-Full 对照。
2. 定点化：冻结 S1 的 int8 权重、24 位累加器、24 位 Q12 膜电位和 T=4。
3. 近似计算：完成 S2 混合 PoT 与 S3 LOA；S3 相对 S1 的历史 Validation Event IoU 下降 0.3931 个百分点。
4. 研究分支：完成 STC、Refiner 适配、独立时空分割、SNN 读出和数据加载优化；未通过升级门槛的方向保留正式负面结果。
5. 硬件契约准备：形成冻结权重、位精确模型和 RTL 黄金向量生成入口；实际 RTL 与 KV260 工作移交第 4 部分。

第一代正式软件证据位于 `implementation/results/`。软件结果、RTL 仿真、综合估算和板级实测必须分开表述。

## 3. 优化、消融与选型

统一使用 [`model_selection_metrics/`](model_selection_metrics/README.md) 的 S01/S02：S01 评估时间步—效果—成本曲线，S02 分解 ANN→SNN、量化、PoT 和 LOA 的效果损失。成本侧遵守正式 B04 口径：MAC、AC 分开统计，比较稠密 MAC 时使用二者之和。

这些研究指标不进入目录 5 的正式主表。仅当候选模型完成冻结并被明确接受为正式模型后，才生成 A/B/C 三类 CSV 对比。

## 4. 后续模型路线

第 1 部分冻结新的 ANN A* 后，建立新的模型版本，不能直接沿用第一代数字：

1. 记录 A* 权重、阈值、特征、数据索引和哈希。
2. 先复现 ANN 基线，再只转换 Proposal，形成新的浮点 SNN。
3. 浮点模型通过精度门槛后，依次进入定点、PoT 和 LOA；每轮只引入一种主要数值变化。
4. 用 S01/S02 完成受控消融和选型，冻结接口后生成黄金向量。
5. 交由第 4 部分建立第二代上板工程；不根据 Validation/Test 反向调结构、阈值、位宽或近似规则。
