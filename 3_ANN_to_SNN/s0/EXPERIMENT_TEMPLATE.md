# 第二代实验登记模板

复制此模板到新实验记录；先填假设、主要变化、预算和入口，再运行。实验 ID 按 `experiment_registry.json` 顺序分配，追加修订记录，不覆盖原结果。

| 字段 | 填写 |
| --- | --- |
| 实验 ID / 阶段 / 日期 / 状态 |  |
| 待证伪假设与阶段入口证据 |  |
| 预注册主要变化、唯一对照变量 |  |
| 冻结教师、索引 SHA-256、特征/时间协议 |  |
| 数据角色与序列、seed、epoch/训练预算 |  |
| 代码修订、权重/缓存 SHA-256、运行环境 |  |
| 整网及目标子集：IoU/AP/Precision/Recall、Proposal 目标召回、候选比例、Refiner 条件召回、高密度 Recall |  |
| 成本：稠密 MAC、有效 MAC、二值 AC、标量操作、状态/队列字节与读写、观察等待、计算与排队延迟 |  |
| 支持解释、反驳、负面结果及混杂因素 |  |
| 继续/修改/停止结论与下一步预算 |  |
| 修订次数、日期、原因、原始记录链接 |  |

对不适用或未测字段填 `不适用` 或 `未测` 并说明原因，不能填 0。正式 Validation 在候选与协议冻结后运行一次，Test 仅用于最终冻结验收。
