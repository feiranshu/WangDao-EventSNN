# ANN→SNN 子项目协作规则

本文件只维护长期规则。当前实现状态、版本结果、命令、有效计划和变更统一见 [README.md](README.md)；历史文档不提供新的执行授权。用户在当前会话中的明确指示优先于本文件。

## 范围

- 本目录负责 ANN→SNN/LIF、STC、定点、PoT、LOA、位精确模型、成本统计和 RTL 黄金向量；ANN 准确性改进归 ../../1_H2_model_improvement/，实际 RTL/综合/板端执行归 ../../4_model_deployment/。
- 教师从 ANN 工程取得冻结版本，记录来源、协议和文件哈希，不修改冻结 ANN。
- software/wangdao/h2/ 和 H2_D1_seed42.npz 是只读历史参考，不能与新教师混用。

## 数据与证据

- Train-main 用于训练/校准，Train-dev 用于开发选型，HW-calibration 用于位宽与近似规则。
- Validation 仅在阶段冻结后复核，Test 仅用于最终冻结模型；如有历史暴露须如实披露。
- 浮点 SNN、定点软件、RTL 仿真、综合和板级实测分开报告。
- 同时记录事件覆盖、阈值、数据角色、后端及运算范围；MAC、AC、额外乘法、状态和访存分别统计。软件操作量不是实测能耗，综合估算不是板测。
- 连续激活不称为脉冲；稠密仿真或解析计数不能冒充实际稀疏 AC 执行。

## 实验与数值纪律

- 一次改变一个主要因素；ANN 教师、学生、阈值、时间步、复位、读出和数值格式版本化。
- 完整 SNN 在单级对照通过后再推进；近似计算先做 exact 对齐，PoT/LOA 首轮不叠加。
- Python 黄金模型与 RTL 的操作顺序、位宽、饱和和复位规则必须对应。
- 保留旧源码、配置、实验、日志、权重和断点；改变数值契约或冻结身份时建立独立版本及运行目录，不覆盖历史。
- 校准/模型选型条件与运行时数值检查分开；不为有限数值新增无依据的幅值硬停止。NaN/Inf、数据与状态完整性问题按版本契约处理。
- 实施后完成与变化相关的回归、数值对齐和必要恢复检查；证据写入 README 并链接原始记录。仅文档整理不启动模型验证或训练。

## 文件、运行与维护

- 正式结果放 results/；过程记录、缓存、checkpoint 和预测放 results/runs/。数据目录联接及本地运行产物遵守已有忽略规则。
- 训练默认由用户启动。代理只在用户明确授权相应模型、运行和预算时启动；历史一次训练授权不自动扩展到续训、其他模型或长期运行。
- 重跑/续训先核对版本、数据、参数和源代码身份；last.pt 与诊断快照区分，不能绕过身份检查复用不兼容断点。
- 修改实现或结论后只更新 README.md 中的状态、结果、有效命令、下一阶段与变更记录，不再另建 PLAN/MIGRATION 状态文档。
- 上级 README 仅提供导航，指标协议只定义口径，本文件只保存规则；不要向它们追加各轮结果或“最新状态”。
- 退出主线的文档遵循仓库根级 archive/ 规则，先保存原文和校验信息，再移除重复入口；归档快照只作历史证据，不继续维护、不作为执行指令。
