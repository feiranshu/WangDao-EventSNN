# 模型优化、消融与选型指标

本目录承接 2026-10-08 正式取消的 `5_model_evaluation` 原 D 类。原 D/C01、D/C02 整体迁入后，为避免与现有正式 C 类编号冲突，连续重编号为 S01、S02。它们只用于 ANN→SNN 过程的模型优化、消融研究和选型，不属于正式 A/B/C 评测主表。

| 编号 | 指标 | 用途与基本条件 |
| --- | --- | --- |
| S01 | 时间步—效果—成本曲线 | 固定数据与评测协议，逐时间步报告 A 类检测效果及相同统计范围内的 B 类算法成本；硬件实测存在时另挂接 C 类数据。 |
| S02 | 转换与数值近似效果损失 | 以冻结 ANN 教师为基线，分别报告 ANN→SNN、量化、PoT、LOA 等单项干预造成的效果差值，不把多种干预合并成来源不明的损失。 |

## 使用规则

1. Train-dev 用于选时间步、结构、位宽和近似规则；Validation 只在阶段冻结后复核，Test 只用于最终验收。
2. 每次受控消融只改变一个主要因素，并保留教师模型、权重哈希、阈值、数值格式、读出、数据索引和协议。
3. S01 的成本曲线必须同时遵守 B04 口径：有效 MAC、有效 AC 分开保存，比较稠密 MAC 时使用 `有效 MAC + 有效 AC`。
4. 软件操作量、综合估算与板级实测必须分开表述。效果损失不能用成本收益抵消，也不合成为未经约定权重的单一分数。
5. 只有最终确认的软件模型才进入 `5_model_evaluation` 的 A+B 分指标 CSV；完成开发板部署的正式配置以独立 `evaluation_id` 进入 A+C。未入选变体继续保存在本目录的研究结果或 `implementation/results/`。

当前 H2/H2-plus 均为 ANN 正式模型，尚无新的可比 SNN 正式结果；因此这里只定义研究口径，不伪造空结果。
