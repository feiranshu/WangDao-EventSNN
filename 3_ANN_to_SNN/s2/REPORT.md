# S2 统一骨架结果 · GEN2-S2-001

日期：2026-10-11。阶段性质：**训练与执行健康检查，不是正式模型选型或保留集精度结论**。数据只使用 Train-main 79 条训练序列和 Train-dev 10 条诊断序列。研究 ANN 与固定位置 SNN 均用 seed42、5 epoch、相同冻结 C1 Proposal 候选和 36 维输入；评价包含全部事件（被 Proposal 拒绝的事件分数为零）。正式 H2-pro ANN 仍是唯一冻结锚点。

## 训练过程与修订

预注册结构、学习率、时间常数、窗口和目标函数见 [`PROTOCOL.md`](PROTOCOL.md)。初版完整运行的 SNN 第一轮输出层发放率 0.774、加权 CE 7.393、裁剪前梯度峰值 1096.7，故停止该运行；原始数据保留于 [`runs/GEN2-S2-001/`](runs/GEN2-S2-001/)。修订只降低权重和读出初始幅度，再以新目录从头进行 79/10、5 epoch 完整复训。两个运行的起始协议快照分别是 [`PROTOCOL_initial.md`](PROTOCOL_initial.md) 与 [`PROTOCOL_at_revision1_start.md`](PROTOCOL_at_revision1_start.md)；后者 SHA-256 与复训 provenance 完全一致。普通和高密度各一对序列的先导运行也单独保留，不计入阶段成绩。

复训研究 ANN 末轮加权 CE 0.1009，5 轮训练总 CPU 时间约 8.0 秒。SNN 加权 CE 从 1.9788 降到 0.2241、Train-dev AP 从 0.7286 升到 0.8105，裁剪前梯度峰值从 224.0 降到 19.2；SNN 5 轮训练累计约 1774 秒，CPU 单线程。两个模型每轮均处理 Train-main 的 2,219,864 个候选事件。研究 SNN 的输出层训练发放比例末轮为 0.418；这明显不是低活动率模型。

## Train-dev 精度

Train-dev 含 1,221,626 个事件、438,966 个候选，候选比例 35.93%，Proposal 目标召回 98.42%。高密度只有 2 条序列，下表的高密度召回不宜解释为稳定的泛化估计。阈值是分别在 Train-dev 上按记录规则选择的研究阈值；0.35 仅作共同参照。

| 模型与阈值 | Event IoU | AP | Precision | Recall | 高密度 Recall |
| --- | ---: | ---: | ---: | ---: | ---: |
| 冻结 H2-pro 正式 ANN，0.35（S1 历史重放） | 0.7926 | 0.9340 | 0.9133 | 0.8571 | 0.5823 |
| 研究 ANN，固定 0.35 | 0.6750 | 0.8899 | 0.7596 | 0.8584 | 0.6402 |
| 研究 ANN，预设网格选择 0.55 | 0.7029 | 0.8899 | 0.8539 | 0.7990 | 0.5483 |
| 研究 SNN，固定 0.35 | 0.4809 | 0.8105 | 0.5122 | 0.8874 | 0.6668 |
| 研究 SNN，预设网格选择 0.60 | 0.6339 | 0.8105 | 0.7226 | 0.8378 | 0.5475 |
| 研究 SNN，**事后**扩展网格 0.75 | 0.6557 | 0.8105 | 0.7965 | 0.7876 | 0.4515 |

预设阈值扫描为 0.20–0.60，步长 0.05；按 Event IoU 最大、同分高密度 Recall 更高、再同分阈值更低选择。SNN 最优点落在上界 0.60，因此额外检查了 0.65–0.95；0.75 是**事后诊断**，不能与预设选择混写。两种口径下 SNN 的全局 IoU 都低于研究 ANN，也低于冻结正式 ANN。0.75 提高全局 IoU 时，高密度召回降至 0.4515。完整混淆计数及阈值曲线见 [`analysis_extended_diagnostic.json`](analysis_extended_diagnostic.json)。

S1 关注的目标子集仅用标签和身份做**推理后**划分，不作为模型输入。以下为预设选定阈值下的完整事件召回，分母含 Proposal 漏筛：

| 子集 | 目标事件 | 研究 ANN 0.55 | 研究 SNN 0.60 |
| --- | ---: | ---: | ---: |
| 首次出现 | 606 | 247 / 606 = 0.408 | 388 / 606 = 0.640 |
| 短时中断再现 | 2,235 | 920 / 2,235 = 0.412 | 1,402 / 2,235 = 0.627 |
| 跨 4×4 单元 | 442 | 136 / 442 = 0.308 | 146 / 442 = 0.330 |

SNN 在首次出现和再现子集的召回高于研究 ANN，但它同时有更多全局假阳性；阈值也不同，不能据此声称时间状态已经修复 S1 错误。跨格样本少且 S1 显示其分布受两条高密度序列主导。子集完整计数见 [`analysis_revision1.json`](analysis_revision1.json)。

## 状态、成本和等待

[`health_revision1.json`](health_revision1.json) 对末轮检查点独立回放了 10 条 Train-dev 序列：权重、状态和概率均有限，发放及成本计数与训练记录完全相同；状态 87×65×88 个 FP32 通道加 FP64 时间戳共 **2,035,800 B**。同时发现膜电位绝对峰值 63.1/54.9/68.9、轨迹峰值 51.7，Train-dev 输出发放比例 0.438。它们没有造成非有限数值，但说明状态可显著超过 0.5 发放阈值，需要在 S3 检查是否由高密度输入、单次最多一脉冲的 soft reset 或读出尺度造成，并按密度拆分。

| Train-dev 成本口径 | 研究 ANN | 研究 SNN |
| --- | ---: | ---: |
| Refiner 稠密结构 MAC | 1,488,972,672 | 1,488,972,672 |
| 跳零有效多值 MAC | 898,524,860 | 480,882,096（输入层） |
| 二值 AC | 0 | 161,852,704 |
| 冻结 Proposal 稠密结构 MAC | 1,958,584,320 | 1,958,584,320 |
| 缓存后 Refiner CPU 回放 | 约 0.34 秒 | 约 8.85 秒 |

SNN Refiner 的多值 MAC 减少约 46.5%，但伴随 AC、状态衰减、读写和读出；当前 CPU 实现实际更慢。冻结 Proposal 的有效 MAC 本轮未重测，不能推出整网有效 MAC 降幅或硬件能耗。SNN 的状态访问、比较、指数衰减与软复位等未完全折成同一种运算单位，详见 [`COST_PROTOCOL.md`](COST_PROTOCOL.md)。闭合窗口的观察等待仍至少持续到 100 ms 窗口右边界；回放耗时不含 Proposal 特征构造、等待或队列。

## 核验与边界

`test_core.py` 和 `test_stream.py` 共 7 项测试通过，覆盖同时间戳、同格、边缘、长静默、空窗口、跨窗口、尾部、重置、梯度、分块一致性与可手算成本。复训 provenance 的索引、冻结权重、特征协议、训练源码及起始协议 SHA-256 均已核对。没有读取 Validation、Test 或 HW-calibration 原始事件。

本阶段支持“参考实现可训练、真实时间状态与闭合窗口回放可重放、计算账目可核对”，不支持“SNN 已追平正式 ANN”或“整网能耗/时延已改善”。下一步只进入 S3 的表示、状态、密度和阈值分解；S4-S 空间传播与 S4-B 背景补偿仍需各自入口证据。
