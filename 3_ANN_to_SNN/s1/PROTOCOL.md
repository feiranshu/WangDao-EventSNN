# S1 分析协议 · GEN2-S1-001

本轮只用冻结 H2-pro 的 Train-dev 十条序列、C1 36 维候选缓存和 exact-int8 权重。阈值固定 0.35，训练预算 0。分析脚本在生成结果前先校验索引、协议、权重、缓存来源及重放混淆矩阵。Validation/Test 与 HW-calibration 不进入分析。

**分析单位**：候选内目标事件；结果变量为冻结 Refiner 是否漏检。各分组可重叠。Proposal 漏筛另报，不能混入候选内比较。下述定义仅用于离线误差诊断，目标 ID、标签和当前完整窗口背景计数不得作为严格事件因果推理输入。

| 分组 | 预定操作定义 |
| --- | --- |
| 跨 4×4 单元 | 同一目标 ID 的相邻两个 25 ms 桶各 ≥3 个目标事件；当前桶与前一桶的目标质心落在不同 4×4 单元，且质心位移 ≥4 像素。仅与有相邻可观测桶的事件比较。 |
| 首次出现 | 同一目标 ID 在该序列首次目标事件后的 100 ms 内。 |
| 短暂中断/再现 | 同一目标 ID 的相邻目标事件间隔 20–200 ms；从再现事件起 20 ms 内。无前驱或超过 200 ms 的重现不归入此组。 |
| 方向变化 | 同一目标 ID 的连续三个 25 ms 桶各 ≥3 个目标事件；由桶质心构成的前、后位移均 ≥2 像素，夹角 ≥60°。只在可观测桶中比较。 |
| 速度变化 | 同上；前、后位移均 ≥2 像素，后/前速度比 ≥2 或 ≤0.5。只在可观测桶中比较。 |
| 局部高背景密度 | 当前闭合 100 ms 窗口、同一 4×4 单元的非目标事件数，高于该序列候选目标事件的第 75 百分位。 |

**匹配控制**：每个序列内部，按该 100 ms 窗口的全部事件数、候选比例和 Proposal 热图特征第 29 列分别以候选目标事件的中位数二分，得到最多八个格。每格暴露/对照各至少 5 个目标候选事件才纳入。以两组较小样本数作为格权重，计算匹配后的漏检率差（暴露减对照），并记录实际覆盖事件数及序列数。原始率和匹配率同时报；无足够共同支持时标记不可判定。序列自助抽样按高密度两条、普通密度八条分别有放回抽取 2,000 次，区间仅衡量这十条序列上的不确定性。一个事件不是独立重复样本。

这些阈值为 S1 探索性操作定义，并非确认机制或因果效应的预注册试验。检验条件是跨序列方向一致、匹配后仍有足够样本和区间不跨零；否则 S1 只形成 S2 的待证伪假设，不启动 S4 的传播或背景机制。

## 定义修订记录

2026-10-11，修订 1：初版把单个目标事件的 4×4 地址变化当成跨格移动，原始输出保留在 `results_initial_event_cell.json`。该定义将目标自身的空间展开误判为运动，暴露率达 26,900/29,699 个可比较候选目标事件。故在查看初版分组结果后改为上表的**目标质心跨格**；这是探索性修订，不可称作结果前预注册，也不将初版/修订版中较有利的结果择优报告。其他五组定义和匹配控制保持不变。
