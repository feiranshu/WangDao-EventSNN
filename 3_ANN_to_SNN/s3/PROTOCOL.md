# S3 训练与状态分解协议 · v1

冻结日期：2026-10-12；依据上级 [`PLAN.md`](../PLAN.md) v1.1 第 4.1 节。此协议先于 S3 新训练和 S3-A 扩展诊断写入。S2 文件、检查点及结果不改写。正式 H2-pro Proposal、C1 36 维缓存、100 ms 闭合窗口与数据五角色不变。只准读取 Train-main/Train-dev 原始事件或其已核验缓存；Validation、Test、HW-calibration 不进入代码入口。

## S3-A · 0 epoch，只读

- 冻结 S2 revision1 epoch5 ANN/SNN 检查点；完整 Train-dev 10 序列，另固定 Train-main 诊断序列 `train_000.npz`、`train_044.npz`、`train_094.npz`。后者只用于现象重复检查，不作为独立泛化集。
- 逐有效候选更新统计每层带符号前/后复位膜电位、阈值以上余量、替代梯度支撑覆盖及发放。输出四原型分别统计连续发放、轨迹/残余读出贡献、原型获胜；按序列、密度、真实标签和同 FP 预算 TP/FP/FN 分组。报告分母及序列计数，事件/神经元不是独立样本。
- 以研究 ANN 已记录 FP=4,137 为主预算、冻结 H2-pro FP=2,463 为补充预算。每个模型各自选择实际 FP 不超过预算、TP 最大的观测阈值；并列分数按真实离散结果处理。保存完整 PR 点，输出总体与高/普通密度 FP、首次出现/再现/跨格候选内 FN。阈值仅作开发集诊断。
- 对同一 SNN 检查点做窗口重置、逐层状态归零、轨迹/残余读出屏蔽推理干预。各干预都独立选择同 FP 诊断阈值；分布外结果只指向重训优先级，不是状态价值结论。
- 分析同格窗口候选数、36 维输入幅度与有符号输出状态及错误关系，不从相关性直接推断重复注入是根因。

## S3-B · 统一口径参考训练

- 新编号 `GEN2-S3-001`，seed42，Train-main 79、Train-dev 10，ANN 和持久状态 SNN 均从 S2 revision1 初始化规则重新开始，预定 epoch5/10 检查点，最多先跑 10 epoch。ANN LR 1e-3、SNN LR 5e-4、AdamW weight decay 1e-4、梯度范数裁剪 5。
- 每 8 个非空 100 ms 窗口构成同一候选集合的优化更新组；序列顺序固定，ANN 不额外打乱候选；SNN 每窗口 TBPTT 截断但数值状态保留。对两者使用 `sum(w[y] * CE) / sum(w[y])`，背景/目标权重 1/3。每轮同时报告全序列无权 CE 和全序列权重和归一化 CE、候选暴露数、优化步数、裁剪次数。
- 每轮保存 Train-dev 完整事件 AP、0.05–0.95 步长 0.05 曲线、总体/高密度指标；用整体 IoU、同分高密度 Recall、更同分低阈值的固定顺序选择。触及边界仅标校准待定。第 10 轮后才评估是否需要统一 30 epoch，不根据 5 epoch IoU 淘汰健康模型。
- 服务器训练先运行无数据合成一致性测试、小数据 CPU 冒烟、角色/哈希前置检查。GPU 若使用，须逐事件预测、状态、损失、梯度和一步更新与 CPU 对齐；若不达标停止正式运行。所有正式输出追加保存、带源码/输入/协议 SHA 和设备记录。

## S3-C/D/E 条件分支

S3-B 回传且确认参考可信后，`GEN2-S3-002` 才训练每 100 ms 窗口重置全部 SNN 神经元/轨迹状态的单一对照，完全沿用 S3-B 的种子、输入、目标、更新组、预算和阈值规则。S3-D 只在 A/C 定位明确问题后选一个单点动力学修订另编编号；S3-E 复核空间传播/背景补偿入口。不得在收到 B 结果前自动把条件分支的结果宣称完成。上传包可包含条件分支代码，但正式运行须分别登记与执行。

训练过程和压缩包均不包含 Validation/Test/HW-calibration 原始事件。包内包含已核验的 89 份 Train-main/Train-dev C1 缓存与冻结元数据，原始数据集由服务器现有路径链接；回传包排除可再生候选缓存，保留历史、日志、检查点、指标、协议锁及 SHA 清单。
