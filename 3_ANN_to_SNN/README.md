## 2. 目标与正式验收门槛

主线是**直接接收原始事件、以神经元状态积累时空证据的 SNN Refiner**。36 维模型继续用作冻结教师、精度参考和人工表示贡献分析，不再是最终 Refiner 输入的默认选择。先固定 H2-pro Proposal 与 100 ms 候选发布时间，单独检验 Refiner 输入改变。严格逐事件发布在 S6 验证，因为闭合窗口 Proposal 仍要求等待右边界。

### 2.1 精度

用户允许原生脉冲方案为了显著简化电路、网络和矩阵运算，相对 H2-pro 有**最多 5 个百分点的绝对下降**。保护线分别作用于同一评分事件及输入期限下的 **Event IoU、Event AP、目标事件 Recall**；不能用一项改善抵消另一项下降。

最终方案还须在可比的 EV-UAV 测试协议下**同时优于** PACT《[Following the Flow: Advection-Consistent Modeling for Event-based Small Object Detection](https://arxiv.org/abs/2606.22378)》的四个论文指标：IoU **75.90%**、ACC／目标事件 Recall **80.05%**、Pd **91.84%**、Fa **0.76×10⁻⁴**。前三项严格高于，Fa 严格低于；四项须来自同一、事先在 Train-dev 冻结的工作点。PACT 的 ACC 在[官方评测实现](https://raw.githubusercontent.com/fulongcai/PACT/main/utils/eval.py)中是目标事件 Recall，不能写成包含背景真负例的普通 Accuracy。

PACT 使用约 8 秒完整事件输入和 1 ms 体素化，本项目已有 H2-pro 成绩采用 100 ms 闭合前缀。设立两张独立结果表：**相同评分事件与期限的系统对照**、**PACT 官方协议的论文门槛对照**。论文报告值、官方权重复测值、本项目同口径值分别标记；未核对事件覆盖、阈值、标签与 Pd/Fa 实现之前，不宣布超过 PACT。论文门槛对照中的尾部未发布事件不得悄悄剔除，须按漏检计入并报告覆盖率。PACT 复测与外部比较不允许借助 Test 调整模型或阈值。

按当前 H2-pro Test 锚点计算，5 个百分点保护线约为 IoU **82.14%**、AP **92.08%**、Recall **89.29%**。这组数仅解释目标；未来正式比较需先锁定相同协议，不能把历史 Test 值直接当作新协议门槛。Precision、高密度 Recall、同 FP 预算召回、首次出现、再现、跨格及目标连续性均需报告；整体达标但关键子集明显恶化时保留为待审候选。

### 2.2 计算和电路简化

精度放宽仅在实现收益得到完整测量后启用。原生 Refiner 的工程入围目标：

1. 部署推理不构造 Refiner 的完整 36 维特征，也不将它重新编码成泊松脉冲。冻结 Proposal 自身需要的前端操作单独保留和计量。
2. 相对冻结 H2-pro 的每候选 **4,480 个稠密 Refiner MAC**，多值突触 MAC 减少至少 **90%**；同时报告同一跳零规则下的有效 MAC。
3. 将状态衰减、读出与专属前处理纳入后，多值乘法总次数争取减少至少 **80%**。S3-R 先核准比较分母；非乘法操作和二值 AC 另列，不视为免费。
4. 相同数值格式下，常驻状态和平均状态读写量不超过 36 维 SNN 参考；权重、事件缓存、队列、峰值带宽分别计量。空间扇出与每事件更新数必须有上限。

这些比例是预设研究目标，不是已有结果，也不是 5/10 epoch 健康检查的机械淘汰线。最终还需报告 **Proposal＋共享前处理＋Refiner** 整链成本。算法计数不能当作 ASIC 面积、时钟或能耗实测。RTL、FPGA/ASIC 实现与功耗实测不进入本轮默认训练链。原计划的整网有效 MAC 降低约 90%、MAC+AC 降低约 50%、10 ms 级观察等待保留为进取目标，不能仅凭替换 Refiner 宣称实现。

## 3. 原生事件 Refiner：首版结构与训练

输入事件为 `(x, y, t, p)`。`x/y` 用于空间寻址，`p` 选择正负极性，`t` 决定更新顺序及惰性衰减；每个外部事件为单位输入脉冲。推理入口不得读取标签、目标 ID、36 维缓存或教师输出。

| 部件 | 首版约定 |
| --- | --- |
| 空间布局 | 保留 346×260 传感器上的 4×4 像素单元，87×65 个有效单元；单元内偏移用于权重寻址 |
| 输入路由 | 候选事件向自身及 3×3 相邻单元投递；边界裁剪，每事件最多 9 个目的单元 |
| 首层突触 | 按极性、单元内偏移与目的单元相对位置选择共享权重，单位脉冲贡献直接累加；不形成稠密统计向量 |
| 通道规模 | 首版 24→16→4；第一层 24 通道按 8/8/8 分组 |
| 时间常数 | 第一层初始 5/25/100 ms，第二层 25 ms，输出及读出轨迹 100 ms |
| 动力学与读出 | 阈值 0.5、替代梯度、soft reset；目标／背景各两个原型，保留脉冲轨迹与残余膜电位读出并计入乘法 |
| 状态生命周期 | 序列开始清零、跨 100 ms 窗口保留；各层记录最后更新时间，按真实时间差惰性衰减 |
| 消息约束 | 首版只做有界前馈，不加入同层递归、动态邻居搜索、可学习延迟或无界队列 |

相邻单元的输入扇出是局部感受野，不等于 S4 的同层传播。首版固定时间常数；只有诊断显示时间尺度失配，才独立比较按通道组共享的可学习时间常数。原生输入不得沿用 36 维权重，必须匹配预算重新训练。

四条必要对照使用相同冻结候选及发布期限：**①**充分训练的 36 维研究 ANN/SNN；**②**相同寻址和状态预算的原生事件连续激活 ANN；**③**仅标签监督的原生事件 SNN；**④**原生事件 SNN＋冻结 H2-pro 教师蒸馏。②用于区分表示不足和脉冲训练不足，计算成本如实列出。人工特征利用了部分非候选事件的背景上下文，所以①与③的差距不能全部归因于脉冲编码。

训练沿用 S3 统一加权 CE、每 8 个非空窗口更新、每 100 ms 截断梯度但保留数值状态。先建立标签监督参考，再单独比较输出蒸馏；蒸馏初值为温度 2、系数 0.5，教师只在离线训练时使用。教师可见完整闭合窗口而学生只见事件前缀时，记录信息期限差异。36 维辅助重建、活动惩罚和量化只在相应诊断后分别启动。

若原生 ANN 与 SNN 都明显落后，先核查缺失的空间或背景信息。只允许一次受控上下文分支：向相同网络加入候选区域及其一圈邻域的**原始事件**，仍只对候选事件评分，单独计量新增事件比例、状态访问和运算。成本不合格即停止，不扩大为默认全事件昂贵网络。

| 阶段 | 工作与交付 | 继续／停止规则 |
| --- | --- | --- |
| **S0–S2 已完成** | 保留冻结契约、错误分组、研究骨架、成本口径和失败记录 | 只重用可信结果，不重跑或改写历史 |
| **S3 现有协议** | 回收并核验 S3-B 服务器 SNN；按原协议决定 S3-C 窗口重置、S3-D 单点修订和 S3-E 入口 | SNN 未核验前不宣布 S3 完成；新输入不混入已锁定实验 |
| **S3-R 表示与评测审计** | 核对 PACT、EV-SpSegNet 的实现、阈值、事件范围、标签与期限；拆分 Proposal、36 维构造、Refiner 的耗时、乘法与访存 | 锁定比较协议及双方成本分母；外部复测与原生开发可并行，但正式 PACT 结论须等复测 |
| **S3-F 人工表示归因** | 固定研究 ANN 训练预算，分别去除坐标、四尺度计数、Proposal 上下文并重训；已有 C0/C1 只作运动列的局部证据 | 确认原生网络优先需要学习的信息；推理置零及相关性不能代替重训消融 |
| **S3-N 原生输入基线** | 实现原生 ANN/SNN，固定候选与 100 ms 发布期限；逐事件正确性验证和首轮训练 | 区分表示、脉冲与优化问题；先建可信参考再开复杂机制 |
| **S3-T 精度恢复** | 先做输出蒸馏；再按诊断仅选上下文、时间常数或动力学中的一项 | 每项单独对照，每机制最多两轮有依据的主要修订，无收益停止 |
| **S4-S 条件空间传播** | 在原生表示上重新核查跨格错误，依次比较普通局部输入、一跳脉冲通信、必要时 MRR，再作复制、方向打乱和多跳对照 | 一跳无可信收益不做多跳；普通局部递归 ANN 是确认阶段的强对照 |
| **S4-B 条件背景补偿** | 有害背景状态积累得到证明后，依次比较普通 LIF、简单归一化／阈值、历史均值补偿 | 不因背景原型发放高而启动，不预先与空间传播组合 |
| **S5 核心确认** | 至多两个候选、关键强对照、三种子、匹配训练预算、配对分析及成本复核 | 保留保护线内、实现更简单且结论可解释的方案 |
| **S6 前端时间协议** | 固定 Refiner，筛查 100/100、100 历史／10 发布、10/10 ANN、10 ms 状态 SNN、严格逐事件方案；改窗口时重训匹配学生 | 原生输入与严格在线因果性分开验收，只有最有价值的两条路线进入完整训练 |
| **S7 组合与部署约束** | 只组合独立有效的模块；分开检验固定点敏感性、衰减查表、状态精度、活动控制与缓冲上限 | 形成 ASIC 算法接口及数值契约，每项近似独立核算精度和成本 |
| **S8 泛化与鲁棒性** | 检验密度、事件稀疏、速度变化、首次出现、再现、跨格与位置分层；外部数据先锁定标签粒度 | 框标注不能冒充真实事件级分割；无可比外部数据时标记未完成 |
| **S9 最终冻结** | 冻结权重、阈值、事件范围、输出期限、状态布局及成本实现后，完成保留集与 PACT 验收 | 同时满足精度和工程条件才晋级；失败则记录未达成，不用 Test 反向修模 |

Train-main **79** 序列用于训练；Train-dev **10** 序列用于诊断、结构和阈值选择；HW-calibration **10** 序列不参与本轮浮点选型。Validation **24**、Test **24** 只在候选及协议冻结后验收，不循环调参。初筛 seed42、10 epoch；训练健康且仍改善的模型在统一 30 epoch 预算下比较后才作能力淘汰。S5 使用 seed42/43/44；记录候选暴露数、优化步数与搜索预算。结果同时给整体 AP／PR、同 FP 预算召回和序列配对分析，区间跨零只代表证据不足。

每个小阶段保存决策卡：**假设、唯一主要变化、输入及训练预算、整体与子集指标、运算／状态／延迟、支持和反驳证据、继续／修改／停止决定、下一阶段预算**。未达到条件入口则跳过。新实验沿用 [`s0/experiment_registry.json`](s0/experiment_registry.json) 的 `GEN2-S<stage>-<serial>` 编号规则，追加记录，不复用编号。

## 5. 接口、验证、成本及论文主张

流式接口沿用 `reset / push / flush_completed_windows / finalize`，原生输入分支与 36 维分支明确区分。每条输出包含事件索引、事件时间、最早合法可发布时间、候选标记、概率和类别；元数据包含输入表示、上下文范围、空间扇出、教师使用方式、数值格式和成本。候选适配器必须生成与冻结 Proposal 一致的掩码、索引及窗口边界，且**不调用 Refiner 的 36 维构造**。

验证覆盖同时间戳顺序、不同输入分块、边缘单元、同格多事件、空窗、长静默、跨窗、未闭合尾窗及序列重置；原生局部更新须与按事件原索引的参考执行一致。GPU 优化先对齐预测、状态、损失、梯度和一步参数更新。严格逐事件分支另验证未来追加不改变过去输出、已发布结果不回写。队列、状态或吞吐超出上限应显式失败并报告，不静默丢事件。

分别统计 Proposal、共享前处理、Refiner 专属前处理、网络、状态衰减及读出；报告稠密／有效多值 MAC、二值 AC、其他标量操作、权重与状态字节、事件缓冲峰值、平均／峰值读写和真实耗时。观察等待、执行时间、队列延迟分开。缓存后的 Refiner 回放时间不能当作整链在线延迟。

人工事件表示是被学术界认可的设计。若 H2-pro 的优势主要来自 36 维统计，应作为表示贡献并用重训消融支持。原作者 EV-SpSegNet 是**稀疏分割网络，不是 SNN**；本项目对它的完整同口径复测仍未完成，论文值不能冒充本项目实测。[EV-UAV 原论文](https://openaccess.thecvf.com/content/ICCV2025/html/Chen_Event-based_Tiny_Object_Detection_A_Benchmark_Dataset_and_Baseline_ICCV_2025_paper.html)

原生事件输入、多时间尺度 LIF、可学习时间常数、蒸馏和普通局部脉冲通信已有研究，不单独宣称首次提出。[ASGCN](https://ojs.aaai.org/index.php/AAAI/article/view/32154)、[FLAME](https://proceedings.neurips.cc/paper_files/paper/2025/hash/1b71649968436c64a765e469ab6b615c-Abstract-Conference.html)。PACT 已研究运动引导的特征传输；MRR 如晋级，须区分状态载体、触发、源端扣减、信息期限和成本。MRR、MRU、BPI 仅按条件入口保留，强对照与负面结果均需报告。核心贡献由证据决定，不预先承诺某机制从未发表或保证 CCF A 录用。

若原生方案不能同时通过精度与工程门槛，保留 H2-pro 正式锚点。少量人工辅助输入可登记为**混合备选**，分别报告成本与精度，不把它算作原生输入路线达标。
