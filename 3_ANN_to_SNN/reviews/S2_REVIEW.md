审查范围包括 S0 冻结契约及决策、S1 分组协议/JSON/报告、S2 初版与复训协议、训练曲线、分析 JSON、健康记录、源代码及测试。原阶段结果、协议和代码未改写。另对现有 revision1 的 SNN epoch5 做逐事件 Train-dev 只读重放，未训练模型、未读取 Validation/Test/HW-calibration 原始事件。该复核不等于 S3 已完成。

- 独立逐事件回放所得 SNN Train-dev AP 为 **0.8105244660240054**，与存储结果完全一致。

- 这些证据支持实现可训练、结果可复现；7 项小型测试不是充分训练、所有统计解释或未来 GPU 实现等价性的证明。

| --- | ---: | ---: | ---: | ---: | ---: |

SNN 第 4→5 epoch 的 AP 从 0.797243 增至 0.810524（约 +1.33 个百分点），加权损失仍在下降。五轮适合作为健康检查，尚不足以判断结构能力上限。SNN 的 AP 落后表明仅选择另一个分类阈值不能消除当前排序质量的差距。

## 2. 训练比较存在需要统一的定义

[`train.py`](../s2/train.py) 的 ANN 调用加权 `cross_entropy` 默认 mean，分母是批次标签权重之和；SNN 在 [`core.py`](../s2/core.py) 累加加权 CE，再由 `train_snn` 除以事件数。两者分别是：

```text
ANN: sum(w[y_i] × CE_i) / sum(w[y_i])
SNN: sum(w[y_i] × CE_i) / N
```

相同 batch 下，两者相差平均标签权重；这个系数会随类别比例变化。简单核验中，一正一负、权重 1/3、全零 logits，二者分别为 0.693147 和 1.386294。这不是 NaN 或标签泄漏问题，但会改变梯度尺度、裁剪行为及各批次相对权重，不能视为已经统一的损失。

此外 ANN 按 4,096 候选批次更新，SNN 每 8 个非空窗口更新（本轮 6,125 个非空窗口对应 766 次优化器更新/epoch）；学习率也不同。相同 epoch 和候选总数不等于相同优化过程。下一阶段要报告这些差异，并统一目标函数与更新组；不必要求不同结构的全部训练超参数数值完全相同，但其选择预算必须一致。

S2 不需要重写或抹去。它完成了健康检查，后续用新编号建立口径明确的参考训练。

## 3. 状态确有值得诊断的现象，原因尚未证明

原 `health_revision1.json` 的膜电位极值是在每个窗口处理完后，对持久状态取绝对最大值：看不到正负号，也不覆盖所有中间更新。本次重放只统计有效候选更新，排除并行填充槽位，得到以下输出层数据：

| 输出层统计 | 普通密度 8 序列 | 高密度 2 序列 |
| --- | ---: | ---: |
| 发放比例（每候选×四输出通道） | 33.48% | 45.15% |
| soft reset 后仍满足 u≥0.5 的比例 | **31.61%** | **41.29%** |
| 发放前 u≥1.5，即三角替代梯度正侧支撑区间之外 | 24.57% | 32.42% |
| 发放前 u≤−0.5，即负侧支撑区间之外 | 60.11% | 49.35% |
| 逐事件复位后膜电位最小/最大 | −74.12 / +38.58 | −64.02 / +16.92 |

阈值为 0.5，每次状态更新最多输出一个脉冲，复位只减 0.5；因此正余量可以保留到后续事件。这符合当前定义，不应直接认作实现 bug。它提示需要检查余量、重复发放、读出尺度与错误之间的关系。

三点限制必须保留：

1. 输出层包括两种类别的原型。背景事件引起背景原型发放可能是正确行为，不能把总输出发放率称为背景噪声误发放。
2. 局部脉冲替代梯度为零不等于全网络梯度消失：残余膜电位读出与连续状态仍可传递梯度。需检查各原型及各分支，而非只看一个发放比例。
3. 普通密度也有显著状态余量；前两层的发放比例反而是普通密度较高。单凭全局“高密度”不能证明 BPI 应当启动。

这些数据的分母为事件×神经元更新，不能当作独立统计样本。后续还需对 TP/FP/FN、每个输出原型、获胜原型和输入率进行配对分解。

## 4. 首次出现与再现有研究价值，当前改善不能归因为记忆

S1 中首次出现与再现的关联比跨格、转向、速度变化更有跨序列支持，仍应作为优先诊断对象。但 S2 在不同阈值下，研究 SNN 的全局 FP=9,732，是研究 ANN FP=4,137 的约 2.35 倍。提高子集召回伴随全局误报上升，尚不能证明状态修复了错误。

高密度子集更明确：ANN/SNN 在各自预设工作点的 TP 分别为 **5,355/5,347**，FP 分别为 **3,288/8,034**，Recall 分别约 **0.5483/0.5475**。两者召回接近，SNN 误报更多。这应优先进入 S3 错误定位，而非继续增加传播能力。

后续先在相同整体 FP 预算下比较子集，再训练“状态保留 vs 每窗口重置”对照。推理时突然清状态或屏蔽读出只用于定位，不能替代按新状态规则重训。当前 36 维输入自身含历史，窗口重置神经元状态也不等于移除所有时间信息。

首次出现时目标可能没有可利用的本序列历史，其错误还可能涉及此前背景状态或冷启动。不能预先把首次出现与再现都解释为目标记忆不足。

## 5. 成本优势要保留，但应缩小表述范围

当前 Refiner 的输入多值 MAC 从研究 ANN 的跳零有效 MAC 898,524,860 降至 480,882,096，另有二值 AC 161,852,704。仅在这组已计连接操作下，MAC+AC 合计约减少 **28.47%**，而不是全部计算减少 46.5%。SNN 还有：

- 38,625,400 次已列状态衰减乘法；
- 36,873,144 次阈值比较；
- 3,511,728 次已列读出乘法，以及读出加法、复位、指数函数等；
- 每方向 38,629,008 通道逻辑读/写及 2,035,800 B 常驻状态/时间戳。

读出 `a×trace+b×u/θ+bias` 也是多值算术，必须在统一 MAC/乘法/加法记账规则下纳入，避免将输入层 MAC 称为模型全部 MAC。固定 Proposal 本轮仅有稠密计数，因此整网有效 MAC 降幅仍未知。

当前缓存后 CPU 回放约 8.85 秒对 0.34 秒，不支持实时速度已提升，也不能由此否定未来合适执行方式的算法成本优势。`available_time_ms` 存储的是窗口右边界，即信息可用时间，并非包含计算耗时的墙钟完成时间。

S2 按独立空间单元打包并行，每层矩阵计算也包含随后被 mask 掉的填充槽位；`.item()`、CPU/设备往返会影响未来 GPU 性能。应先测填充率和同步开销，再决定 GPU 优化。当前 CPU 已能完成五轮有限训练，GPU 改造不应成为只读诊断和所有短程参考实验的强制前置任务。

## 6. 后续任务的具体调整

| 原任务 | 本次决定 | 原因 |
| --- | --- | --- |
| S3 并行探索特征、网格、记忆、调度 | 收敛为训练口径→状态诊断→预算对齐→状态重训对照 | 当前结构归因存在混杂；过早并行会扩大搜索 |
| 优先 MRR/MRU | 延后，仍需入口证据 | 当前不足主要还没有定位到跨空间信息丢失 |
| 高密度问题优先 BPI | 不成立，保持条件启动 | 总输出发放不等于背景污染，普通密度也有状态余量 |
| 继续扩大阈值搜索 | 下一轮运行前统一范围，辅助报告 AP/PR 与同 FP 预算 | 已知阈值偏移，无法解释全部排序差距 |
| 立即否定 36→48→32→4 SNN | 不采纳 | 第五轮仍在改善，且训练口径未统一 |
| 继续训练到 30 epoch | 有条件保留 | 先形成健康、可比较的参考；10 epoch 作阶段决策点 |
| 所有 10/30 epoch 训练必须先迁移 GPU | 改为按实测预算决定 | 原规则会让工程优化阻塞小规模科学诊断 |
| 表示删改、空间粒度、KD、活动惩罚 | 等待针对性证据 | 不与基础训练/状态对照叠加 |
| H2-pro 冻结、数据角色、S5 三种子、S6 后置 | 保留 | 本次结果未推翻这些边界 |

执行预算与各结果分支详见 PLAN 4.1 节。S2 原决策卡保留为当时记录；其“先实现 GPU 再做 10/30 epoch”要求由本次执行计划修订为条件项。S3 预留编号继续保持未开始；此次没有训练新模型，也没有宣称发现新的论文创新。
